# ソフトテニス部 戦績管理

練習試合・大会の結果を、生徒がスマホでボタンを押すだけで記録し、個人・ペアの戦績（勝敗・勝率）や日ごとの結果を見られるアプリです。

- アプリ：https://aoyagi01-oss.github.io/softtennis/ （GitHub Pages を有効にした後）
- データは先生の Google ドライブのスプレッドシートに保存されます（無料・期限なし）

## しくみ

```
生徒のスマホ ── アプリ（GitHub Pages）
                   │  Apps Script がつなぐ（部の合言葉が必要）
                   ▼
           Google スプレッドシート
            ├ 「選手」シート … 石川県内の選手名簿
            └ 「試合」シート … 1試合1行
```

## できること

| 画面 | 内容 |
|---|---|
| 試合入力 | 自分の名前は端末が覚え、よく組むペア（最近の試合で多い人）が自動で入ります。大会名と試合の形式は、同じ日ならアプリを開き直しても残ります。相手校・相手選手・スコアもボタンで選ぶだけ。7ゲームが基本で、5・9・3ゲームも選べます。3-3（5ゲームなら2-2）になったときはファイナルの点数も入れられます。途中で終わった試合（打ち切り・棄権）、相手の名前がわからない試合、**部内の自校対決**も入力できます。電波が悪いときは「送信待ち」になり、つながったとき・アプリに戻ったときに自動で送ります（同じ試合が2回入ることはありません）。 |
| 戦績 | 個人・ペアごとの試合数・勝・負・勝率。男女、自校／ほかの学校、年度・期間、大会で絞り込めます。名前を押すと、ペア別・相手校別・対戦相手別の成績と試合の記録が出ます。 |
| 日別 | 選んだ日の結果を、男女別・学年順の一覧で表示します（印刷もできます）。 |
| 選手 | 選手の追加。先生用の合言葉を入れると、名簿の一括取込・修正・引退・削除、新年度の学年繰り上げができます。 |
| PDF取込 | 大会の組み合わせ・結果の PDF から自校のペアと近くの相手を探し、選ぶだけで試合入力に移れます。 |

勝率は、ふつうに決着した試合で計算します（戦績画面のチェックで、途中で終わった試合も含められます）。

## 最初に1回だけ：準備

### 1. スプレッドシートを作って Apps Script を貼る

1. Google ドライブで新しいスプレッドシートを作る（名前の例：「ソフトテニス部 戦績」）
2. メニューの **拡張機能 → Apps Script** を押す
3. 最初から入っている文字をすべて消し、[`apps-script/Code.gs`](apps-script/Code.gs) の中身を貼り付ける
4. 上のほうの3か所を書き換える
   - `PASSWORD`：**部の合言葉**（生徒に伝える）
   - `ADMIN_PASSWORD`：**先生用の合言葉**（生徒には教えない）
   - `HOME_SCHOOL`：自校の名前（`金沢錦丘` のまま）
5. 💾（保存）を押す
6. 右上の **デプロイ → 新しいデプロイ**
   - ⚙ の「種類の選択」で **ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（生徒の私物スマホからも使えるようにするため。合言葉がないとデータは見られません）
   - **デプロイ** を押し、アクセスを承認する
     （「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」→「許可」）
7. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピーし、[`config.js`](config.js) の `API_URL = ''` の `''` の中に貼る

> Apps Script を後で書き換えたときは「デプロイ → デプロイを管理 → ✏ → バージョン：新バージョン → デプロイ」で反映します（URL は変わりません）。

### 2. GitHub Pages を有効にする

リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main` ／ `/ (root)` にして Save。数分で `https://aoyagi01-oss.github.io/softtennis/` が開けるようになります。

### 3. 名簿を入れる

1. アプリを開いて部の合言葉を入れる
2. 「選手」タブの下の **先生用の合言葉を入れる**
3. **令和8年度 県新人大会の名簿を取り込む** を押す（男女 528 人、自校は男子13人・女子12人）
4. 自校の選手の学年を「直す」で入れておくと、日別の一覧が学年順になります

名簿は組み合わせ表から作ったので**名字だけ**です。同じ学校に同じ名字が2人いる場合は「中川①」「中川②」のように番号を付けています（「直す」で名前を変えられます。変えても過去の戦績はそのまま残ります）。

## 生徒への伝え方

1. アプリの URL を Classroom などで配る
2. 部の合言葉を伝える
3. 初回に自分の名前を選ぶ（次から自動で入ります）
4. ホーム画面に追加しておくと便利です（iPhone：共有 →「ホーム画面に追加」、Android：︙ →「ホーム画面に追加」）

## 運用メモ

- スプレッドシートを直接直しても反映されます（列の順番を変えても大丈夫です。見出しの名前は変えないでください）。
- 試合を消せるのは、その試合を入力した端末と、先生用の合言葉を入れた端末だけです。
- 新年度は「選手」→ 先生用メニュー →「自校の学年を1つ上げる」を1回押します（3年生は「引退」になり、入力画面の名前の一覧に出なくなります。戦績は残ります）。
- 別の大会の名簿は、エクセルから「学校・氏名・性別・学年」の4列をコピーして、先生用メニューの「名簿をまとめて取り込む」に貼ります。
